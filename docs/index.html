credential manager for git

MANY IDENTITIES.
ONE GIT.

Pick an account per command: git commit --vault work. Author, HTTPS token, SSH key and SSO sign-in switch together, and nothing is written to your git config. Think aws-vault, for git.

$ brew install chungquantin/tap/git-vault

01 // WHY

Work, personal, a client. Different emails, tokens, keys. Global git config can only be one of them.

◆

per-command identity

user.name, user.email and signing key injected with -c for that command only. Two terminals, two accounts, no state to flip.

◆

HTTPS, SSH, SSO

Token via a scoped credential helper, an IdentitiesOnly SSH key, or git vault login for a browser/SSO sign-in.

◆

secrets stay secret

Tokens live in the macOS Keychain. The helper answers only for the vault's host, so a work token never hits the wrong server.

◆

agent-ready

Ships a Claude Code skill so your AI agent commits as the right account, and knows when to hand the passphrase prompt to you.

02 // HOW IT WORKS

A tiny shell function routes --vault to git-vault run, which execs the real git with per-invocation overrides.

03 // INSTALL

    
Python 3.8+ and git. No dependencies.

    

      
      
      
    


    

      
brew install chungquantin/tap/git-vault

      
# latest from main
brew install --HEAD chungquantin/tap/git-vault

    

    

      
curl -fsSL https://raw.githubusercontent.com/chungquantin/git-vault/main/install.sh | sh

      
# also wire up your shell rc
curl -fsSL https://raw.githubusercontent.com/chungquantin/git-vault/main/install.sh | sh -s -- --shell

      
Installs to ~/.local/bin. Override with PREFIX=, pin with GIT_VAULT_VERSION=v0.1.0. Uninstall: install.sh --uninstall.

    

    

      
git clone https://github.com/chungquantin/git-vault.git
cd git-vault && ./install.sh --shell

    


    
then enable the shell function

    
echo 'eval "$(git-vault shell-init)"' >> ~/.zshrc && source ~/.zshrc
git-vault doctor
