git-vault

Multiple git identities and credentials, picked per command. Like aws-vault, for git.

GitHub · Install · Use · Claude skill

Work, personal, a client: different emails, tokens and SSH keys, but git has one global config. git-vault injects a named identity (author, HTTPS token, SSH key, signing key) into a single git command. Nothing is written to your git config.

bash
git commit --vault work -m "fix: typo"
git push   --vault personal

Install

bash
# Homebrew
brew install chungquantin/tap/git-vault

# or curl
curl -fsSL https://raw.githubusercontent.com/chungquantin/git-vault/main/install.sh | sh

Then enable the shell function and check the setup:

bash
echo 'eval "$(git-vault shell-init)"' >> ~/.zshrc && source ~/.zshrc
git-vault doctor

Needs Python 3.8+ and git. The shell function is what makes git add vault and --vault work; git vault <cmd> works without it.

Use

One vault per account. Each does its own browser sign-in:

bash
git add vault --name personal --user-name "Me" --email me@gmail.com --no-token
git vault login --name personal    # browser opens: sign in as that account

git add vault --name work --user-name "Me" --email me@corp.com --ssh-key ~/.ssh/id_work --no-token

git clone  --vault work git@github.com:corp/app.git
git commit --vault work -m "msg"
git push   --vault work

Manage vaults:

bash
git vault list
git vault show work
git vault set --name work --email new@corp.com   # edit fields, token untouched
git vault remove work
GIT_VAULT=work git pull                          # env alternative

How it works

For the one command only, git-vault passes:

  • -c user.name / user.email, plus user.signingkey and commit.gpgsign if set.
  • A credential helper for HTTPS that answers only for the vault's host, so a work token never goes to the wrong server.
  • GIT_SSH_COMMAND="ssh -i KEY -o IdentitiesOnly=yes" for SSH remotes.

Tokens are stored in the macOS Keychain (a 0600 file elsewhere). git vault login uses gh auth login --web in a throwaway config dir, so SSO sign-in happens in the browser and your own gh accounts are untouched.
